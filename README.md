# personal-website-outdated

An archive of personal site designs that were replaced. Superseded. The current site is https://gabrieldalton.com.

Two things are kept here.

`local/website/` is a complete copy of an earlier build: `home.html`, a `thank-you.html` confirmation page, and the whole `assets/` tree of CSS, JS, logos and project images it needs.

`older_options/` holds two layouts that were tried and dropped. `Home.html` is the formal version, titled "Environmental Tech Pioneer". `casual.html` is a lower case take on the same introduction. A headshot is the only asset either of them uses.

Nothing here is deployed or maintained. It exists so the earlier drafts are not lost.
